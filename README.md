# テキストテンプレ (TextTemplate) for AviUtl ExEdit2

テキストの見た目(フォント・色・文字装飾・縁取り/グラデーション等のフィルタ)をテンプレートとして登録し、
タイムラインで選択したテキストへ**ボタン1つで一括適用**する AviUtl2 用の汎用プラグイン(.aux2)です。

| 項目 | 内容 |
|---|---|
| 対応 | AviUtl ExEdit2 2.1.16 以降(動作確認: 2.1.16) |
| 種類 | 汎用プラグイン(`TextTemplate.aux2`) |
| ライセンス | MIT([LICENSE](./LICENSE) / [THIRD_PARTY_NOTICES.txt](./THIRD_PARTY_NOTICES.txt)) |
| ダウンロード | [Releases](https://github.com/Leolla-gz/TextTemplate/releases) の `TextTemplate_v*.au2pkg.zip` |

---

## 特長

- 見た目を作り込んだテキストを選んで「選択から登録」するだけで、**テキスト設定とフィルタ効果を丸ごと**テンプレート化
  - テキスト設定: フォント・サイズ・文字色・影/縁色・文字装飾(標準文字/縁取り文字 等)・B/I・字間・行間・文字揃え 等
  - フィルタ効果: グラデーション・何重もの縁取り・グロー・ぼかし 等、種類を問わず(順序・有効/無効も保持)
- **単数・複数どちらの選択にも一括適用**。テキスト以外(画像等)は自動でスキップ
- **サイズ・拡大率/位置は、適用するかをパネルのチェックで都度選択**(字幕の位置は保ったまま見た目だけ揃える、等)
- 「上書き」で、既存テンプレートを選択中テキストの今の見た目に更新
- 一覧の各行に **「あAa漢」のプレビュー**(多重縁取り・グラデーション・シャドーを近似表示)とフィルタ構成を表示
- 適用は **Ctrl+Z で元に戻せる**(1回の適用 = 1回の Undo)

---

## インストール

1. [Releases](https://github.com/Leolla-gz/TextTemplate/releases) から `TextTemplate_v*.au2pkg.zip` をダウンロード
2. AviUtl2 を起動し、zip を**プレビュー画面へドラッグ&ドロップ**(`.au2pkg.zip` は AviUtl2 がそのままインストールできる形式)
3. 求められたら AviUtl2 を再起動

AviUtl2 カタログからもインストールできます。

アンインストールはプラグインフォルダの `TextTemplate\TextTemplate.aux2` を削除してください。

## 使い方

AviUtl2 のメニューに追加される「**テキストテンプレ**」ウィンドウを開きます(他のウィンドウと同様にドッキング可能)。

| ボタン | 動作 |
|---|---|
| 選択中に適用 | 一覧で選んだテンプレートを、タイムラインで選択中のテキストへ適用(一覧のダブルクリックでも可) |
| 選択から登録 | 選択中のテキストの見た目(フィルタ含む)を新しいテンプレートとして登録 |
| 上書き | 一覧で選んだテンプレートを、選択中テキストの見た目で更新(名前は維持・確認あり) |
| 新規 / 編集 / 削除 / ↑ / ↓ | テンプレートの手入力作成・編集・削除・並べ替え |
| サイズ・拡大率も適用 | オン時のみ、テキストの「サイズ」と標準描画の「拡大率」「縦横比」を適用 |
| 位置も適用 | オン時のみ、標準描画の「X/Y/Z」「中心X/Y/Z」「X/Y/Z軸回転」を適用 |

### 使用例

| やりたいこと | 操作 |
|---|---|
| 今あるテキストの見た目を登録 | テキストを選択 →「選択から登録」→ 名前を付けて OK |
| 「二重縁+グラデ」の字幕スタイルを作る | 1つのテキストに 縁取り×2・グラデーション を付けて仕上げ →「選択から登録」 |
| 字幕の位置はそのまま、見た目と大きさだけ揃える | 「サイズ・拡大率も適用」オン、「位置も適用」オフで適用 |
| 複数の字幕に一括反映 | タイムラインで Ctrl+クリック等で複数選択 → テンプレートを選んで「選択中に適用」 |
| 字幕ごとのフェードは残したい | 登録時にフィルタ一覧で「フェード」のチェックを外し、「既存フィルタを置き換える」をオフ |
| 失敗したので戻す | AviUtl2 の「元に戻す」(Ctrl+Z) |

- 画面下の状態表示に「2個のテキストに適用 / テキスト以外1個はスキップ」のように結果が出ます

### テンプレートで扱う内容

| 区分 | 内容 | 適用時の動き |
|---|---|---|
| テキスト設定 | フォント・文字色・影/縁色・文字装飾・B・I・字間・行間・文字揃え 等 | 上書き。編集画面で空欄・■にした項目は変更しない |
| サイズ系 | テキストの「サイズ」、標準描画の「拡大率」「縦横比」 | 「サイズ・拡大率も適用」オン時のみ |
| 位置系 | 標準描画の「X/Y/Z」「中心X/Y/Z」「X/Y/Z軸回転」 | 「位置も適用」オン時のみ |
| 対象外 | テキスト本文・長さ自動調節、標準描画の透明度・合成モード | 変更しない |
| フィルタ効果 | 縁取り・グラデーション・グロー 等、何個でも | 上から順に追加。「既存フィルタを置き換える」がオンなら先に既存フィルタを削除 |

### 編集画面で変更できる項目

| 項目 | 例 | 備考 |
|---|---|---|
| フォント | `Yu Gothic UI` | AviUtl2 に登録されたフォントから選択 |
| 文字色 / 影・縁色 | `ffcc00` | 16進6桁(RRGGBB)。「選択...」で色選択ダイアログ |
| 文字装飾 | `縁取り文字` | 候補から選択 or 直接入力 |
| B / I | 太字 / 斜体 | 3状態(オン / オフ / ■=変更しない) |
| サイズ | `60.00` | 動きのある値(`100,1,1,直線移動,0`)もそのまま保持 |
| フィルタ一覧 | `縁取り  サイズ=4, 縁色=ffffff` | チェックを外すとテンプレートから除外(値の編集は不可) |
| 既存フィルタを置き換える | オン / オフ | 「選択から登録」した物は既定オン、それ以外は既定オフ |

### 保存場所

- テンプレート: `<AviUtl2 のアプリケーションデータフォルダ>\Plugin\TextTemplate\templates.ini`(UTF-8 テキスト)
- チェックの状態: 同じフォルダの `settings.ini`
- `templates.ini` をコピーすれば別 PC への移行・バックアップができます

## 注意事項・制約

- **プレビューは近似表示**です(Windows 標準の GDI で描画)
  - 再現するのは 縁取り(多重)・グラデーション・シャドー と文字装飾のみ。ぼかし・グロー等は名前だけ表示
  - AviUtl2 の Font フォルダにだけ置いたフォントは、プレビューで代替フォント表示になる場合があります(適用は可能)
- **既存フィルタの置き換え**がオンだと、字幕ごとに付けたフェード等も消えます(Ctrl+Z で戻せます)
- **フィルタの値は編集画面で変更できません**。AviUtl2 上で見た目を直して「選択から登録」または「上書き」してください
- 文字装飾を手入力した名前が AviUtl2 と異なる場合、状態表示に「設定できない項目」と出ます。「選択から登録」で取り込むのが確実です
- パネルは Windows 標準の明るい配色です(ダークテーマ非対応)
- AviUtl2 はベータ版のため、本体の更新で動作しなくなる場合があります。不具合は [Issues](https://github.com/Leolla-gz/TextTemplate/issues) へ

## 開発者向け情報

### 構成

```
AviUtl2 本体
 │ 起動時に .aux2(=DLL)を読み込み、決まった関数を呼ぶ
 ▼
src/plugin_main.cpp ── RegisterPlugin() でパネルを作り register_window_client() で登録
 ├ main_window.cpp ── パネル(ボタン・一覧・状態表示)
 │   ├ edit_dialog.cpp ── テンプレート編集ダイアログ
 │   ├ preview.cpp ───── 「あAa漢」プレビュー描画(GDI)
 │   └ text_object.cpp ── SDK でテキストオブジェクトを読み書き(適用・取り込み)
 ├ template_store.cpp ── テンプレート ⇔ 保存ファイル文字列 の変換(Windows 非依存・単体テスト可)
 └ util_win.cpp ──────── UTF-8/UTF-16 変換、ファイル入出力、色変換
```

### 適用処理の流れ

```
「選択中に適用」
  → call_edit_section_param()(編集ロックを取り、1回の Undo にまとめる)
     → 対象 = get_selected_object(0..n-1)。0個なら get_focus_object()
     → 各オブジェクト(「テキスト」効果を持たない物はスキップ):
          ① set_object_item_value() でテキスト設定・標準描画の各項目を設定(サイズ/位置はチェック時のみ)
          ② 置き換えオンなら get_effect_list() → 種別が「フィルタ」の物を delete_effect()
             (種別は enum_effect_name で取得。種別不明の物は消さない)
          ③ テンプレートのフィルタを順に create_effect() → set_effect_item_value()。無効だった物は set_effect_enable(false)
```

- 設定値の書式は AviUtl2 のエイリアス(.object)と同じ
- 「選択から登録」は `get_object_alias()` の文字列を分解して取り込むため、未知のフィルタ・項目も取り込める

### 保存形式(templates.ini)

```ini
; AviUtl2 TextTemplate plugin data v2 (UTF-8)
[Template]
name=字幕(二重縁+グラデ)
replace_filters=1
text.フォント=Yu Gothic UI
text.文字色=ffffff
text.文字装飾=標準文字
text.サイズ=48.00
draw.effect=標準描画
draw.X=0.00
draw.Y=400.00
draw.拡大率=150.000
[Template.filter]
effect.name=グラデーション
開始色=fff27a
終了色=ff7a2e
[Template.filter]
effect.name=縁取り
effect.disable=1
サイズ=6
縁色=e0457b
```

- `[Template.filter]` は直前の `[Template]` のフィルタ(書いた順に適用)。`effect.disable=1` は無効状態
- v0.1 の旧形式(`[Template]` 直下に `フォント=…`)も読み込み可能(既存フィルタは残す扱い)
- 不明なキーは無視するため、将来項目を増やしても旧版で読める
- 書き込みは一時ファイル → 置き換え方式(保存途中で落ちてもファイルが壊れにくい)

### ビルド

| 環境 | コマンド(このフォルダで実行) |
